## ✨ Features

* 🇮🇳 **Authentic 3D Waving Tricolor**: Complete with an animated 24-spoke Ashoka Chakra rendered with CSS conic gradients.
* ⚡ **Live Realtime Counter**: Powered by Firebase Realtime Database and atomic transactions for instant synchronization.
* 🛡️ **Pillars of Valour Marquee**: Infinite smooth scrolling carousel showcasing iconic freedom fighters.
* 📜 **Freedom Struggle Timeline**: Historical turning points from 1857 to August 15, 1947.
* 📱 **Fully Responsive**: Dark-mode glassmorphic interface styled across mobile and desktop.

---

## 🛠️ Tech Stack

* **Frontend**: HTML5, CSS3, Vanilla JavaScript
* **Database**: Firebase Realtime Database
* **Hosting**: GitHub Pages / Netlify
